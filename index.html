Preferencias y privacidad

Mi espacio

Nombre del espacio

Los datos de esta versión se guardan localmente en este navegador y dispositivo. GitHub Pages aloja la aplicación, pero no guarda tus movimientos. Para usarla en otro dispositivo, exportá e importá el respaldo. No ingreses números de tarjeta, claves bancarias ni información sensible.

Esta primera versión es un prototipo de prueba, todavía no una herramienta financiera auditada. Probá primero con datos ficticios.
