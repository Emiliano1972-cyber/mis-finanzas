# Mis Finanzas · Prototipo inicial

Aplicación web de finanzas personales, en un único archivo HTML, pensada para probarse desde el teléfono.

## Ejecutar
- Abrí `index.html` en un navegador moderno, o publicalo en GitHub Pages.
- Los datos se guardan en `localStorage` de ese navegador y dispositivo.
- Usá **Informes y cierres → Cargar datos ficticios** para probarla.
- Usá **Exportar respaldo JSON** para guardar una copia recuperable.
- El botón **Descargar / guardar PDF** abre la función de impresión del navegador. Elegí “Guardar como PDF”.

## Importante
Este es un prototipo inicial. Antes de usarlo con datos financieros reales, hay que probar y corregir los cálculos y los flujos de cierre. GitHub Pages solo aloja los archivos; no sincroniza ni respalda los datos. No se debe ingresar información bancaria sensible.
